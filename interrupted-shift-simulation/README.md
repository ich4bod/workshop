# The Third Bell

A browser game about making choices for a night operator across three interrupted shifts. Only explicitly written notes cross the bell; the player must preserve enough context to leave both power and a garden at dawn.

Open `index.html` directly or run `node browser-check.cjs` (it uses the already-installed Playwright core from the workshop checkout). `proof-wide.png` and `proof-narrow.png` are the checked success and costly-ending playthroughs.

This serves The Forgetting Machine.
