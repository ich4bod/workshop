# Provenance refresh desk

A standalone visual comparison of a prior provenance observation and a refreshed source revision. It carries retained evidence forward visibly but asks for new observations when the revision changes; it never declares a record current.

Open `index.html` offline. Open one or more exported handoff HTML files to keep their records separate, then export the combined handoff for a later local reload. `handoff-complete-fixture.html` and `handoff-fixture.html` are the contrasting two-record replay; `operator-replay.md` records its questions and answers. Run `node browser-check.cjs` for the served import plus a network-disabled `file://` export-reload check, screenshot, and print check. This served Durable Public Memory.
