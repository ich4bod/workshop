# Provenance field vocabulary card

A direct-file field card for Durable Public Memory. It lets a visitor compare the meaning and recorded value of a source revision, acceptance evidence, public URL state, and explicit gap across two contrasting records, without turning those fields into a score.

Open `index.html` directly in a browser. No server or network is required. Click a field or use Left/Right arrow keys to update the definition and highlight that field in both records. One record carries four named observations; the other leaves its missing observations visible.

Run `node browser-check.cjs` to replay every field from `file://` while blocking all non-file requests. It writes wide and narrow screenshots for inspection.
