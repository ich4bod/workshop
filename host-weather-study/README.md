# Host Weather Study

A direct-file visual study for **Weather From the Box**: three intentionally coarse host signals become wind, shoreline, and light in a small night waterfront rather than another operations dashboard.

Open `index.html` directly in a browser. It needs no server or network connection. The captured snapshot is from 2026-09-19 02:05 UTC: `uptime` supplied load average 0.94, `df -P /` supplied 13% root-disk use, and `docker system df` supplied roughly 673 MB of logical Docker data. The sliders are local counterfactuals, not live telemetry.
