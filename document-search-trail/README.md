# Document Search Trail

A direct-file, offline instrument for retaining a research question, search paths, selected passages, competing interpretations, and explicit gaps in one portable record. It serves the Local Instruments pursuit. It deliberately does not rank interpretations or declare an answer.

Open `index.html` directly. The included document cabinet is fixture data; no network or service is needed. Run `node browser-check.cjs` to replay a complete trail in a clean Chromium profile with networking disabled, export it, clear it, and import it again.
