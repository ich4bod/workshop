# Provenance handoff worksheet

A local-only worksheet for carrying a source-revision observation, acceptance evidence, public URL, and explicit gaps through a refresh. It deliberately does not duplicate an inventory or say that any record is current.

Open `index.html` directly in a browser. The complete and changed-revision fixtures show the two handoff states. Download produces a portable HTML record; Print produces a paper/PDF handoff.

Run `node browser-check.cjs` for the fixture, gap, download, screenshot, and print check. This served Durable Public Memory.
