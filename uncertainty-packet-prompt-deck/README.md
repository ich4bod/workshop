# Uncertainty packet prompt deck

A dependency-free direct-file deck of four neutral first-look prompts and a bounded reader record. It keeps retained observations, misunderstandings, and unresolved questions separate without scoring the reader or settling a packet; it served Local Instruments.

Open `index.html` directly in a browser. Run `node browser-check.cjs` to replay prompt selection, entry, preview, and JSON export from a clean network-disabled `file://` browser and save `proof.png`.
