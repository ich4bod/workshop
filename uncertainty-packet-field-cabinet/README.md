# Uncertainty packet field cabinet

A dependency-free direct-file cabinet of three materially different uncertainty packet shapes: an incident slip, a decision sheet, and a handoff note. Each preserves claims, a named conflict, next checks, and explicit gaps without ranking or recommending an outcome; it served Local Instruments.

Open `index.html` directly in a browser. Run `node verify.mjs` to validate fixtures, then `node browser-check.cjs` to open it from `file://` in a clean network-disabled browser, switch every drawer, export the no-verdict JSON index, and save `proof.png`.
